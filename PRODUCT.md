## Platform

web

## Stack

Decided in `CRIMSUN_POOL/TDD_SPARK_SOL_PROTOCOL.md`, following the prompt packs: Python 3.11 standard-library server on `127.0.0.1:4700`, one HTML page, Ollama, VoiceStudio, faster-whisper. No npm app.

## Users

The operator of F.L.A.X.E.O.N, at the Windows desk, asking a private folder of markdown notes a question with the network unplugged.

Draven is the only user. Nobody else operates the page, and there is no audience to design for. The on-camera Wi-Fi-off check in the TDD is a self-proof, not a demo for viewers.

## Product Purpose

SPARK SOL Protocol is F.L.A.X.E.O.N's fully local notes instrument. It turns a markdown folder into a sky, answers only from those notes, speaks in a cloned voice, and hears on this machine. Success is a turn the operator can trust with Wi-Fi off: the cited note is visible, and the voice that speaks is the local one.

## Positioning

A cloud assistant cannot truthfully claim this. The corpus never leaves the machine, and every answer points at the notes it used.

## Operating Context

Evening desk. The display is the lamp. Hands-free listening and a bottom input are both normal. Test tabs use `?mute=1`. The Desk HUD and TEMPEST SOL are sibling surfaces. This protocol does not take the HUD microphone.

## Capabilities and Constraints

Local brain, local voice, local ears, a growing note file, a spoken brain switch, and a drill that lists every outbound host. Live web research is not a feature of this build. Wake aliases are Spark, hey Spark, Flaxeon, and hey Flaxeon. The plate keeps the full name.

The first page runs against the parent F.L.A.X.E.O.N memory database, not a stub and not the markdown allowlist. Canonical tables are `memory_facts`, `memory_sessions`, and `memory_documents` in Neon, opened only through the parent's `memory/neon_store.py` and `memory/config_manager.py`. The connection string stays in the parent's `config/api_keys.json`. This folder never copies it and the page never receives it. When Neon cannot be reached, the reader uses the parent's local mirror `memory/long_term.json`. Fact categories are identity, preferences, projects, relationships, wishes, and notes. A star's color is that category. The plate names the fact key or the document name. On the sky, one faint name marks each region. A star's own name appears when it is focused, cited, or under the cursor.

The CrimSun markdown allowlist in `CRIMSUN_POOL/SPARK_SOL_CORPUS.md` is a later index, about 5,700 files after duplicate `chunks` copies are dropped. It is not what the first page loads. Raw repositories, skill files, virtualenvs, and key files are not notes.
